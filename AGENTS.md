# Contributor boundaries

- **Copy:** edit page JSON under `src/mouse_click_stability_analyzer/resources/strings/` (not `terminology.json`). Do not rename keys or placeholders. Run `check_strings.bat`.
- **UI layout:** edit Qt layout/style. Do not change string JSON unless asked.
- **Terminology:** edit `terminology.json` for shared engineering terms. Page files use `{@term.key}`. Do not redefine a canonical term in page files.
